# Agent Context: Guardians of Verdantia Demo

This file provides context to the AI agent about the project's technical stack and conventions.

## Core Technologies

- Unity 2022 LTS
- C#
- 2D URP (Universal Render Pipeline)

## Key Architectural Patterns

- ScriptableObjects for data configuration (Towers, Enemies, Waves).
- Singleton pattern for `GameManager` to manage global game state.
- Event-driven UI updates to decouple UI from game logic.
- Component-based architecture with MonoBehaviours for game objects.
