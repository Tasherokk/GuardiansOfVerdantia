# Quickstart: Tower Defense MVP

This guide provides the essential steps to get the Tower Defense MVP project running in the Unity Editor.

## Prerequisites

- **Unity Hub**: Make sure you have the Unity Hub installed.
- **Unity 2022 LTS**: The project is built with Unity version 2022 LTS. Please ensure you have this version installed through the Unity Hub.

## Setup

1.  **Clone the Repository**:
    ```bash
    git clone <repository-url>
    ```
2.  **Open the Project in Unity**:
    - Open the Unity Hub.
    - Click the "Open" button.
    - Navigate to the cloned repository's root folder and select it.
    - Unity will automatically import the project and all its dependencies. This may take a few minutes.

## Running the Game

1.  **Open the Main Scene**:
    - In the Unity Editor's "Project" window, navigate to the `Assets/Scenes` folder.
    - Double-click the `Forest01` scene file to open it.

2.  **Play the Game**:
    - With the `Forest01` scene open, press the **Play** button at the top of the Unity Editor.
    - The game will start, and you can begin playing the first wave.
